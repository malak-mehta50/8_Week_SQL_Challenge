# 8_Week_SQL_Challenge

Welcome to my personal solutions for the #8WeekSQLChallenge created by Danny Ma. This repository showcases my journey through eight real-world business case studies, all designed to strengthen and demonstrate advanced SQL skills in a practical, story-driven format.

🧠 What This Repository Includes
This challenge spans across industries — from restaurants and subscriptions to banking and marketing — and covers a wide variety of SQL topics such as:

✅ Joins & Aggregations

✅ Window Functions & Ranking

✅ Common Table Expressions (CTEs)

✅ Case Statements & Conditional Logic

✅ Date & Time Manipulations

✅ Text Functions

✅ Filtering, Sorting & Grouping

✅ NULL Handling & Data Cleaning

Each case study folder contains:

- Cleanly formatted SQL solutions

- Output result screenshots

- Explanations for each question

Diagrams or insights (where relevant)

💡 Why I Did This
As a Business Analytics Master's student at UMass Amherst with experience in marketing data and analytics, I wanted to sharpen my SQL skills through project-based learning — and this challenge was the perfect fit.

Every query here reflects not just technical execution, but my thought process in approaching complex problems, optimizing queries, and simulating real-world business scenarios.

🔧 Tools Used
PostgreSQL (local setup via pgAdmin)
